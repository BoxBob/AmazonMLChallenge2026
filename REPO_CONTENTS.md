# What is in this repository

This repository holds everything from the Amazon ML Challenge 2026 entity-resolution work that GitHub can store:
- all code;
- the notebooks, executed with their outputs;
- every trial's run logs and validation scores;
- the version ledger;
- the final predictions.

The final submission is **v11**, with a leaderboard score of **0.977**. The full history is in [`VERSION_FINDINGS.md`](VERSION_FINDINGS.md): versions v0–v12, trial ledger T00–T37 and pitfall ledger P01–P24.

## Map

| Path | Contents |
|---|---|
| `VERSION_FINDINGS.md` | The ledger: every version, trial and pitfall, with examples, decisions and leaderboard results. |
| `NEXT_PLAN.md` | The research plan written after v10, covering phases A–F. |
| `code/src/` | Notebooks for every version, from the baseline to v12. |
| `code/experiments/` | Experiment, diagnostic and builder scripts (`make_v*.py` → `*_src.py` → notebook). |
| `versions/<trial>/` | Per-trial archive: `metrics.json`, `MANIFEST.md` with the SHA-256 of each output file, executed notebook and run log. |
| `work/<trial>/` | Run logs, executed notebooks, `val_scores.csv` and JSON results of every run; `work/run_*.sh` are the exact launch scripts. |
| `work/v3`, `work/v9`, `work/v11` and `work/v12` `*_model/` | Model configs and tokenizer configs only, no weights. |
| `submission/pkg/` | The final package layout: `Documentation_template.md` (filled methodology), `code/business_entity_resolution/` (README with the exact run order, `requirements.txt`, sources) and `output/matching_results.tsv` (final v11 predictions, 98 MB). |
| `utils/validate_submission.py` | The organizers' submission validator. |

Git tags mark every trial: `v3` … `v11`, `v11-lb0977`, `final-v11`, `v12-exp`.

## Not included, and why

| Not included | Size | Reason | How to get it back |
|---|---|---|---|
| `dataset/` | 2.4 GB | Competition data; files are over GitHub's 100 MB limit. | Download from the competition. |
| The problem-statement PDF | 172 KB | The organizers' document; this repository is public. | The competition page. |
| `work/` caches | about 70 GB | Normalized records, TF-IDF/SVD embeddings, kNN arrays, pair feature stores, test chunk checkpoints and bi-encoder embeddings. Single files reach 9 GB. | Regenerated by the notebooks and scripts, in the run order in `submission/pkg/code/business_entity_resolution/README.md`. |
| Model weights (`*.safetensors`) | 0.1–0.5 GB each | Over the 100 MB limit. | `exp_v9_mce.py`, then `exp_v11_mce.py` (cross-encoders); `exp_v12_biencoder.py` (bi-encoder). |
| `candidate_pairs*.tsv` | 0.9–1.8 GB each | Over the 100 MB limit. | Written by each version's notebook. The SHA-256 of each is in `versions/<trial>/MANIFEST.md`. |
| Older `matching_results_*.tsv` | about 98 MB each | Only the final v11 file is committed, to keep the repository small. | Re-run the version's notebook; check it against the SHA-256 in its `MANIFEST.md`. |
| `work/papers/` | – | Extracted text of published papers (copyrighted). | The links are in `VERSION_FINDINGS.md`. |
| Sample dumps of raw records | – | Excerpts of the competition data. | – |
